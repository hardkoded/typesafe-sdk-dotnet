Typed System One judgments in C#.

TypeSafe’s System One models (including Jev) turn application state into structured Choice, Score, and Noul answers your code can use directly. This package is a .NET port of @typesafe-ai/sdk, not an official TypeSafe product. 

dotnet add package TypeSafe.AI.Sdk

Quickstart

Set TYPESAFE_API_KEY, then ask a Choice — same shape as the JS quickstart.

using TypeSafe.AI.Sdk;

using var client = new TypeSafeClient();
var response = await client.SystemOneAsync(
    new { document = "I was charged twice. Please fix this ASAP." },
    new Dictionary<string, Question>
    {
        ["category"] = Question.Choice("What is this ticket about?", new Dictionary<string, object?>
        {
            ["billing"] = null,
            ["technical"] = null,
            ["other"] = null,
        }),
    });

Console.WriteLine(response.GetChoice("category").Choice);

Question types

NeedBuilderAnswer
One of a defined set Question.Choice choice, probabilities, confidence
Degree on ordered levels Question.Score score, legend, probabilities, confidence
Is this true? Question.Noul noul ∈ [0, 1] — no separate confidence

Batch independent questions in one SystemOneAsync request. Retries, env vars, and errors match the JS SDK.
